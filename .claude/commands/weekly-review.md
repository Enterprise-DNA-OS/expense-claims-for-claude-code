Run: `npm run expense -- weekly-review`

Run /attention first, then this. Write five lines: what is waiting on whom, what is ready to batch, card charges to chase, the checks that failed (GST documents first), and spend this month by entity. Use /draft-review if the operator wants it written up.

Options use --name=value. Add --json for structured output. Show money with its currency, GST included unless stated. Drafts go to drafts/ and are never sent from here. Nothing here pays anyone.
